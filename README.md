# QueryTube

QueryTube is a web application that helps users search, explore, and interact with YouTube content efficiently through a user-friendly interface.

## Features

* Search YouTube videos quickly
* Clean and responsive user interface
* Fast query processing
* Easy navigation and video discovery
* User-friendly design

## Tech Stack

* Python
* HTML
* CSS
* JavaScript
* Jupyter Notebook

## Project Structure

```text
QueryTube/
│── src/
│── assets/
│── notebooks/
│── README.md
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/sindhubhukya710/QueryTube.git
```

2. Navigate to the project directory:

```bash
cd QueryTube
```

3. Install required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application.

## Usage

* Open the application.
* Enter a search query.
* Browse the results.
* Select videos for more details.
